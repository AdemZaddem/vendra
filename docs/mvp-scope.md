# MVP Scope

## Build first (MVP)

- Merchant organization and staff access
- Merchant dashboard
- Public storefront link
- Products, images, sizes, colours, prices
- Inventory per variant
- Customer records (created automatically from orders, matched by phone number)
- Cart and checkout (guest checkout, no login required)
- Cash on Delivery (COD)
- One online payment provider (Flouci or Paymee)
- Payment webhook confirmation
- Order management
- Manual delivery status updates
- Delivery zones and prices
- Basic revenue, order, and low-stock analytics
- Manual SaaS plan assignment (merchant contacts Vendra, pays manually, admin activates plan)

## Later (valuable, not required to launch)

- Delivery-company integrations
- WhatsApp/SMS automation
- Instagram/Facebook catalogue sync
- Custom domains
- More storefront themes
- Advanced discounts and promotions
- Returns portal
- Multi-location inventory
- Mobile app
- Advanced analytics
- Customer-facing accounts (order history, saved addresses)

## Not in v1 (explicitly excluded)

- Marketplace with multiple sellers
- Holding merchant/customer money
- Building a delivery company
- Advanced ERP/accounting system
- Multi-country support
- Complex AI features
- Automated recurring subscription billing (Vendra bills merchants manually)

## MVP success test

A Tunisian clothing seller can:

- [ ] Create a merchant store
- [ ] Add a product with size/color variants
- [ ] Publish the product on their public storefront
- [ ] Share the storefront link on Instagram/Facebook
- [ ] Receive a COD test order
- [ ] Receive an online-payment test order
- [ ] View the order in the merchant dashboard
- [ ] Update its delivery status
- [ ] See stock reduce for the purchased variant
- [ ] See the order/revenue in basic analytics

## Why an MVP

An MVP proves whether Tunisian social sellers will pay for a tool that helps them receive and manage orders better, before investing months building features nobody needs. Everything in "Later" gets built based on real merchant feedback, not upfront guesses.
